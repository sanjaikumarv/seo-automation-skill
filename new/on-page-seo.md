# On-Page SEO Optimization

## Objective

Identify on-page SEO improvements.

## Required Inputs

- Website URL
- Website Name
- WEBSITE_AUDIT_RESULT
- KEYWORD_RESEARCH_RESULT
- COMPETITOR_ANALYSIS_RESULT

## Instructions

1. Review important website pages.
2. Evaluate title tags.
3. Evaluate meta descriptions.
4. Review H1, H2, and H3 structure.
5. Evaluate keyword placement.
6. Review content quality and search intent.
7. Check internal linking.
8. Review image alt text.
9. Review structured data and schema markup.
10. Recommend content improvements.

## Output

Return:

- Page-wise SEO findings
- Recommended title tags
- Recommended meta descriptions
- Heading improvements
- Content recommendations
- Internal linking suggestions
- Schema recommendations
- Priority-based action plan

## Rules

- Do not modify the website.
- Provide recommendations only.
- Avoid keyword stuffing.
- Use all previous skill results.

## Completion

Return ON_PAGE_SEO_RESULT.
