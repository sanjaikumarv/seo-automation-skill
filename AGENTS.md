# Workspace Guidelines for AI Agents: Multi-Workflow Automation

## Operational Directives

1. **Workflow Execution & Orchestration:**
   - Execute workflows defined in `workflows/` using `.agents/skills/master-orchestrator/SKILL.md`.
   - **SEO Workflow (`workflows/seo-workflow.json`):**
     1. `.agents/skills/seo-audit/SKILL.md` ➔ writes `outputs/seo-audit-report.md`
     2. `.agents/skills/keyword-research/SKILL.md` ➔ writes `outputs/keyword-research-report.md`
     3. `.agents/skills/content-generation/SKILL.md` ➔ writes `outputs/generated-content.md`
   - **Resume Workflow (`workflows/resume-workflow.json`):**
     1. `.agents/skills/resume-analysis/SKILL.md` ➔ writes `outputs/resume-analysis-report.md`
     2. `.agents/skills/content-generation/SKILL.md` ➔ writes `outputs/tailored-resume.md`
   - **Content Workflow (`workflows/content-workflow.json`):**
     1. `.agents/skills/keyword-research/SKILL.md` ➔ writes `outputs/keyword-research-report.md`
     2. `.agents/skills/content-generation/SKILL.md` ➔ writes `outputs/generated-content.md`

2. **Inter-Skill Data Dependencies:**
   - Every downstream skill must read the output files generated by previous skills from `outputs/` before generating recommendations or content.
   - Ground all recommendations on the discovered URLs, target keywords, or ATS gap findings from upstream steps.

3. **Artifact Persistence:**
   - Save all deliverables in `outputs/` using deterministic file naming.
   - Maintain execution status in `logs/pipeline-state.json`.

4. **Data Integrity:**
   - Never fabricate search volume numbers, keyword rankings, PageSpeed scores, or candidate credentials.
   - When external analytics access is unavailable, clearly document it as a research limitation.
